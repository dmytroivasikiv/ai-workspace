# Update durable memory

1. Verify the claim and search scoped memory for an existing note.
2. Prefer a regression test, then project guide/rule, workflow skill, global preference note, project note, or current task ledger—in that order of fit.
3. Update instead of duplicating; keep the note atomic and sourced.
4. Exclude secrets, production values, transcripts, raw logs, diffs, and speculation.
5. Run `"$HOME/.local/bin/aiw-memory-lint"` and `"$HOME/.local/bin/aiw-memory-index"`. These installed launchers are independent of the current project directory.
6. Show the exact changed path; never answer only "remembered".
